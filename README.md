# Speaky classroom audio

Audio assets used by the Speaky coding classroom. The website loads these files separately from its Neocities pages.

- `tutorial-*.mp3`: eight supplied tutorial dialogue clips.
- `speaky-*.wav`: supplied character voice clips.
- `glass_006.ogg`, `maximize_009.ogg`, `toggle_002.ogg`, `bong_001.ogg`: Kenney Interface Sounds; see Kenney-License.txt.

No website source, account credentials, local filesystem paths, or Python runtime are included.
Character voice files are not covered by the Kenney license. No additional license is granted for those recordings here.
